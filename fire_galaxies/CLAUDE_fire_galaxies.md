# `fire_galaxies/` — Reference

This directory contains CII and IR luminosity data extracted from FIRE cosmological simulations at z = 6 and z = 8. The data are used to calibrate and validate CII line intensity models (particularly `SilvaCII` and `LichenCII` in `mass_luminosity.py`) against galaxy-scale simulation output, and to produce the L_CII vs L_IR diagnostic plots.

**Source**: Liang et al. (via personal communication / pre-publication data). Contains output from two FIRE sub-projects:
- **MassiveFIRE**: zoom-in re-simulations of individual massive halos (5 galaxies at z=6, 6 galaxies at z=8)
- **FIREBox**: uniform-volume periodic box simulation with many lower-mass galaxies (57 galaxies at z=6, 29 at z=8)

---

## Data Files

All data files share the same three-column format: `GalID  log10(L_CII/L_sun)  log10(L_IR/L_sun)`.

### `CII_IR_info_Liangetal_z6.txt` and `CII_IR_info_Liangetal_z8.txt`
The original formatted data files with section headers and the simulation-internal galaxy IDs. Human-readable but not directly machine-parseable due to the section header lines. These are the primary data deliverables from the Liang et al. collaboration.

**z = 6 ranges** (from file):
- MassiveFIRE: log L_CII ∈ [5.14, 9.29], log L_IR ∈ [8.73, 13.33]
- FIREBox: log L_CII ∈ [2.14, 7.97], log L_IR ∈ [8.73, 11.41]

**z = 8 ranges** (from file):
- MassiveFIRE: log L_CII ∈ [6.57, 8.89], log L_IR ∈ [10.37, 13.01]
- FIREBox: log L_CII ∈ [0.00, 6.82], log L_IR ∈ [8.37, 10.35]

Notable outliers: galaxy ID 160 at z=6 has log L_CII = 2.14 (extremely faint CII relative to L_IR ~ 8.83); galaxy ID 24 at z=8 has log L_CII = 0.00 (absent or unresolved CII emission). These likely represent galaxies with suppressed CII due to AGN feedback or very low gas metallicity.

### `fire_galaxies_z6.dat` and `fire_galaxies_z8.dat` (v1)
Machine-readable versions of the data. MassiveFIRE galaxy IDs are replaced with `-1` (a sentinel indicating "MassiveFIRE origin") to allow flat loading without section-header parsing. FIREBox galaxies retain their original IDs (0, 1, 2, ...). CII and IR values are identical to the `CII_IR_info_Liangetal` files.

### `fire_galaxies_z6_v2.dat` and `fire_galaxies_z8_v2.dat` (v2)
Updated versions with revised CII luminosities. L_IR values are unchanged from v1; L_CII values are systematically higher (roughly +0.3 dex for most galaxies). This revision likely reflects an updated CII emission model or line radiative transfer post-processing in the FIRE pipeline. The same MassiveFIRE `-1` sentinel convention is used.

**v1 vs v2 L_CII comparison (z=6, first MassiveFIRE galaxy)**:
- v1: log L_CII = 8.318, log L_IR = 11.689
- v2: log L_CII = 8.376, log L_IR = 11.689 (L_IR unchanged)

## Plot Files

### `fire_galaxies.png` / `fire_galaxies.pdf`
L_CII vs L_IR scatter plot for the FIRE galaxies (likely combining z=6 and z=8, both MassiveFIRE and FIREBox). Used for comparing FIRE simulation output against observational L_CII–L_IR relations and against model predictions from `SilvaCII`.

### `fire_cii_ir.pdf` / `fire_cii_ir_v2.png`
Corresponding plots using the v2 (updated CII) luminosities. The `_v2` suffix tracks which version of the data was used.

## How These Files Are Used

These files are not directly imported by the WebSkyLIM pipeline at runtime. They serve as:

1. **Calibration targets**: When tuning the `SilvaCII` or `LichenCII` model parameters, the FIRE galaxy luminosities can be compared against model predictions via `mass_luminosity.SilvaCII(M, MLpar, z)` evaluated at the halo masses corresponding to the simulated galaxies.

2. **Diagnostic plots**: The L_CII–L_IR relation from FIRE provides a reference line for validating whether the adopted L_CII(SFR) relation (from Silva et al. 2015) reproduces the FIRE galaxies' positions on the L_CII–L_IR plane.

3. **Scatter characterisation**: The spread in the FIRE galaxy L_CII at fixed L_IR informs the log-normal scatter parameter `sigma_scatter` used in `Mhalo_to_Lline`.

To load the machine-readable files in Python:
```python
import numpy as np
# v1: MassiveFIRE have GalID = -1, FIREBox have GalID >= 0
data = np.loadtxt('fire_galaxies/fire_galaxies_z6.dat')
galid, logLCII, logLIR = data[:,0], data[:,1], data[:,2]
massivefire = data[galid == -1]
firebox      = data[galid >= 0]
```

## Notes

- There is no code in the repo that imports or auto-loads these files — they are used interactively/for plotting only.
- The `-1` GalID sentinel in the v1/v2 `.dat` files is not documented anywhere else in the codebase; it is purely a convention of this directory.
- The v2 L_CII values are the more current calibration; prefer v2 for any new comparisons unless specifically reproducing v1 results.
- The `fire_cii_ir_v2.png` filename suggests the plots are generated by a script not committed to the repo (likely an analysis notebook or standalone plotting script).
